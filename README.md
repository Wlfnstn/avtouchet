# АвтоУчёт

PWA для автомобилистов в Казахстане: https://wlfnstn.github.io/avtouchet/

- **ТО по пробегу и времени** — масло, жидкости, фильтры, расходники; прогноз даты замены по вашему среднему пробегу.
- **Пробег** — еженедельное напоминание и автоматическая оценка текущего пробега.
- **Документы** — страховка ОГПО ВТС, техосмотр, налог на транспорт (до 1 апреля), права и свои документы; к каждому можно прикрепить PDF или фото (хранятся в IndexedDB на устройстве).
- **Калькулятор налога на транспорт** — по объёму двигателя, году выпуска и месяцам владения (Налоговый кодекс РК с 2026 г., МРП 4 325 ₸).
- **Чек АЗС по фото** — литры, цена, сумма и вид топлива распознаются на телефоне (Tesseract.js).
- **Расходы** — график по месяцам: топливо, ТО и ремонт, документы; стоимость месяца и километра.
- **Цены на топливо каждый день** — средние по Казахстану, 14 городам и сетям АЗС; GitHub Actions ежедневно обновляет `prices.json` (источник creditbureau.kz).
- **Напоминания** — уведомления (фоновая проверка в Chrome на Android), значок на иконке, экспорт сроков в календарь (.ics).
- Работает офлайн, данные хранятся только на устройстве; резервная копия — Экспорт/Импорт (⚙︎), приложение раз в месяц напоминает её сделать.

## Обновление

После изменения файлов увеличьте `VERSION` в `sw.js`, чтобы установленные приложения получили новую версию.
