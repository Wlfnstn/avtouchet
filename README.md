# АвтоУчёт

PWA для автомобилистов: учёт интервалов ТО (масло, жидкости, фильтры, расходники), история обслуживания, журнал заправок с расчётом расхода и цены на топливо в Казахстане.

- Работает офлайн, устанавливается на главный экран (Android / iOS / компьютер).
- Данные хранятся только в браузере на устройстве; для резервной копии — Экспорт/Импорт в настройках авто (⚙︎).

## Обновление

После изменения файлов увеличьте `VERSION` в `sw.js`, чтобы установленные приложения получили новую версию.
